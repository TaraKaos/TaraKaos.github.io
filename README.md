# Portfolio Starter

This is a simple portfolio project designed for learning.

## Goal
Build a personal portfolio page with:
- a hero section
- a project gallery
- an about section
- a simple content source for easy updates

## Recommended learning approach
1. Open the project in VS Code.
2. Read each file in order.
3. Type the code yourself instead of copying from a finished app.
4. Change the content in `data/projects.js` whenever you finish a project.
5. Refresh the page to see your changes.

## Project structure
- `index.html` – page structure
- `styles.css` – styling
- `script.js` – page logic
- `data/projects.js` – project data for the CMS-like content

## How to view it locally
Open the folder in VS Code and either:
- use the Live Server extension, or
- run this in the terminal:

```bash
cd /home/tara/Development/Portfolio
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Learning tasks
- Add your name and intro in `index.html`
- Add a project card style in `styles.css`
- Read the data object in `data/projects.js` and add your own projects
- Make the page render those projects automatically in `script.js`

This setup is intentionally simple so you can understand how HTML, CSS, and JavaScript work together.
